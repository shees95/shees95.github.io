# 타이틀 UI 분리와 환경설정 정리

타이틀 UI에 함께 들어 있던 화면들을 분리하고, 환경설정을 여러 화면에서 사용할 수 있도록 정리했다.
UI의 외형과 실제 열기·닫기 동작을 함께 다듬는 작업이었다.

## 시각 요소 정리

UI의 보더, 음영, 애니메이션, 하이라이트, 폰트를 조정했다.
화면별 스타일을 정리하고 버튼의 선택 상태와 상호작용을 쉽게 구분할 수 있도록 다듬었다.

기능이 연결되어 있어도 현재 어떤 항목을 선택했는지 잘 보이지 않으면 사용하기 어렵다.
선택과 반응이 화면에서 드러나도록 시각 요소를 정리했다.

## 재사용을 위한 위젯 분리

### 버튼 재사용
버튼은 하나만 만들어 모든 버튼들에 재사용하여 델리게이트만 개별 연동시켜주는 식으로 재사용하였다.

### 타이틀 위젯 재사용
기존에는 `Title` 위젯 안에 `Join`, `ChoiceMap`, `Settings`가 함께 들어 있었다.
특히 Settings를 다른 화면에서도 사용해야 해서 각 화면을 개별 위젯으로 분리하고 부모 관계를 재구성했다.

하지만 위젯을 분리하는 것만으로 재사용이 끝나지는 않았다.
화면마다 열기와 닫기 연결이 달라 Settings가 의도대로 닫히지 않는 문제가 남았다.


## ESC 닫기 동작 통합

ESC 입력 시 UI Manager가 HUD를 제외한 최상단 UI를 닫도록 변경했다.
여러 화면이 열려 있어도 현재 위에 있는 화면부터 닫을 수 있도록 닫기 동작을 통합했다.

```text
ESC 입력
    ↓
UI Manager에서 닫을 최상단 UI 확인
    ↓ HUD 제외
해당 UI 닫기
```

이 변경으로 화면을 닫는 문제는 해결했지만, 각 화면의 버튼 이벤트와 델리게이트 연결은 개별 설정이 필요했다.
기존에 분리해 둔 처리 함수를 활용해 버튼과 이벤트를 연결했다.

위젯 구조를 나누는 작업과 화면별 동작을 연결하는 작업이 각각 필요하다는 점을 확인했다.

## 해상도와 화면 모드 선택

맵 선택 UI에서 사용한 `ComboBox String`을 활용해 해상도와 화면 모드 설정을 추가했다.

선택 변경 델리게이트에서 어떤 항목이 선택됐는지 확인하고, 표시 문자열을 실제 설정에 필요한 값으로 변환하도록 연결했다.

| 선택 항목 | 변환할 값 |
|---|---|
| 해상도 문자열 | 가로·세로 해상도 값 |
| 화면 모드 문자열 | 선택한 화면 모드에 대응하는 값 |

표시용 문자열을 설정값으로 변환한 뒤 해당 값을 적용하는 흐름이다.
화면에서는 읽기 쉬운 이름을 사용하고, 실제 적용 단계에서는 해상도와 화면 모드에 맞는 값으로 처리했다.
