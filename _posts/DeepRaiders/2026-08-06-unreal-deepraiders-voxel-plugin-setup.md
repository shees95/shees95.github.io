# DeepRaiders 개발 - 복셀 플러그인 적용

DeepRaiders는 지하를 개척하며 팀 거점을 탈환하는 게임이다. 플레이어가 직접 지형을 파고 이동할 수 있어야 하므로, 지형을 실시간으로 수정할 수 있는 복셀 플러그인을 프로젝트에 적용했다.

---

## 플러그인 설치

플러그인 적용 과정은 생각보다 간단했다.

1. 플러그인을 프로젝트의 `Plugins` 폴더 아래에 추가한다.
2. 언리얼 에디터의 플러그인 설정에서 해당 플러그인을 활성화한다.
3. 사용하는 모듈의 `Build.cs`에 필요한 의존성을 추가한다.
4. 프로젝트 파일을 갱신한 뒤 에디터를 다시 실행한다.

프로젝트 전용 플러그인은 엔진 설치 폴더가 아니라 프로젝트 아래에서 관리하는 편이 프로젝트를 공유하거나 버전을 맞출 때도 편리하다.

## 적용 확인

복셀 전용 월드를 부모로 하는 월드를 생성한 뒤 `Voxel Tool::Remove Sphere`를 임의의 위치에 적용했다. 지정한 위치의 지형이 구 형태로 제거되었고, 비어 있는 공간이 절차적으로 만들어지는 것을 확인했다.

이 테스트로 DeepRaiders에서 필요한 핵심 기능인 실시간 굴착이 가능하다는 것을 확인했다. 다음 단계에서는 복셀 월드가 실제로 생성되는 범위와 크기 설정을 확인하기로 했다.

---

## 정리

- 프로젝트의 `Plugins` 폴더에 플러그인을 추가하고 에디터에서 활성화했다.
- `Build.cs`에 필요한 모듈 의존성을 추가했다.
- `Remove Sphere`로 런타임 지형 제거가 정상적으로 동작하는 것을 확인했다.
